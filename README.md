# FoilBench · 烫箔印样检查

FoilBench 对照版图检查烫箔照片，区分版图内的缺箔与留白区发现的疑似箔色。它还保留检查参数和对应照片，方便复核或把图表交给印刷同事。

## 启动

运行 ./start.sh，打开 http://127.0.0.1:19889/。运行 ./start.sh stop 可关闭容器并保留命名数据卷。可设置 FOILBENCH_PORT 使用别的端口。Docker Compose 服务默认只在本机环回地址开放。

也可在 Python 3.11 或 3.12 的独立环境中安装 requirements.txt 并运行 python -m foilbench，默认端口为 8000，数据目录为 runtime-data。

## 检查一份印样

1. 载入合成练习，或导入白色烫箔区、黑色留白区的版图，以及已对齐的灯 A 照片。可同时导入灯 B 照片。
2. 切换灯光与版图，画检查窗或点图面读原始颜色。输入箔色门槛、毫米每像素及最小斑块数后可保留设置。
3. 选择转移覆盖、连续缺箔、留白越界、像素剖线、箔色参照或箔色分布。可圈箔色和纸色作为参照，或者在图面划一条剖线。从斑块或剖线表点回原照片像素核对。
4. 保存正在看的检查。从存档重开，再下载 CSV、标记图及检查当时的照片。
5. 需要先处理照片时，进入照片准备。生成一份尺寸完全一致的照片结果后，可返回当前印样并设为灯 B 照片。已有检查继续使用原存档的照片。

## 双灯转移覆盖

同时导入灯 A、灯 B 照片后，转移覆盖自动升级为双灯检查，沿用同一版图、检查窗和箔色门槛；只有一张照片的印样继续使用原来的单灯检查，其余检查项目不受影响。

- 两盏灯一致检出的版图位置按一致结果判：都有箔记为已转移，都无箔记为缺箔。
- 两灯有分歧时，把分歧像素按四邻域连成组件。组件在版图内、且与两灯一致确认的箔有至少两个四邻接触点（即沿一条边接续箔形，暗细线两端相接时必然满足），整段救回为已转移；缺口内仅单灯发亮的孤立点只有一个偶然接触点，不会被当成转移。
- 证据仍不足的分歧位置标为待复看，标记图用琥珀色显示，缺箔仍为红色。留白区的单灯亮点同样标待复看，不进覆盖率的分子或分母。
- 覆盖率只按可确认的版图像素（已转移与缺箔）计算，待复看像素与面积在表中单独列出。
- 点检同一源坐标时同时给出两盏灯的 RGB、箔色分、单灯判定和当前综合判定。整个仲裁只使用集合运算与连通性，对调两盏灯得到完全相同的判定。

## 输入范围

检查图接受单帧 PNG 和 JPEG，单张最高 14 MiB，总像素上限为四百万，每边至少八像素。工作台保存统一为 PNG 的版图及照片。源图必须预先对齐并同尺寸，版图亮度达到 128 即归入设计烫箔区。检查窗以像素为单位，末端边界排除。斑块按四邻域连接，报告列出最多 120 个最大斑块。长剖线最多等距读取 1000 点。

方向光是独立检查的观察条件。箔色是相对于蓝色通道的暖色差指标，会受照明、纸张光泽和烫箔材料影响。检测值用于定位复看，印样材料和光照条件由操作者现场判断。标有「合成图像」的样本由程序生成，包含计划内颜色变化和人造斑块，不代表现场测量。
